# Room Rental Web App

A web application built using **Node.js**, **Express**, **MongoDB**, and **EJS**, designed to allow users to rent out their rooms or search for available rentals. Inspired by the concept of Airbnb, this app includes features like room listing, search, and filtering to enhance user experience.

---

## Features

- **Room Listing**: Users can list their rooms by providing details such as location, price, amenities, and photos.
- **Search Functionality**: Search for rooms based on keywords like location, price range, or amenities.
- **Filter Options**: Filter rooms by price, availability, number of guests, and more.
- **Responsive UI**: User-friendly design with mobile compatibility.

---

## Tech Stack

### Backend
- **Node.js**: Runtime environment.
- **Express**: Web framework for building APIs and handling server-side logic.
- **MongoDB**: NoSQL database to store room and user data.

### Frontend
- **EJS**: Template engine to render dynamic content on the server.

### Other Tools
- **Mongoose**: For MongoDB object modeling.
- **Body-Parser**: Middleware to parse request bodies.
- **dotenv**: Manage environment variables.
- **Bootstrap & CSS3 : For styling the application.
